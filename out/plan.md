## Component breakdown (untagged — architectural)
- app/src/components: NavBar, Hero, HeroDemo, FeatureSection, demos/GoalDemo, demos/CurriculumDemo, demos/WhiteboardDemo, ChatPanel (shared), ExploreSection, LearnCard, CtaSection, Footer, icons.tsx
- app/src/hooks: useInViewAutoplay (IntersectionObserver play/pause/loop), useScriptedTimeline (drives demo steps from data)
- app/src/data/demoScripts.ts, courses.ts (explore cards), philosophyLesson.ts
- **Backend seams (frontend-only build, user will add backend later):**
  - src/services/types.ts — domain model (User, Session, Message, Course, Topic, Lesson, LessonPart, WhiteboardNote, TutorEvent)
  - src/services/api/client.ts — fetch wrapper, base URL from import.meta.env.VITE_API_BASE_URL
  - src/services/api/TutorApi.ts — interface: createSession, listSessions, getSession, sendMessage (streaming hook), generateSyllabus, getCourse, getLesson, createLessonNotes
  - src/services/api/mockTutorApi.ts — in-memory + scripted mock (powers the demos today)
  - src/services/api/index.ts — getTutorApi() factory: real ApiClient if VITE_API_BASE_URL set, else MockTutorApi
  - .env.example documenting VITE_API_BASE_URL / VITE_USE_MOCK_API
- BACKEND.md at repo root: everything omitted for later (real AI generation/streaming, auth, persistence, the 9 /ai-tutor/[slug] course subpages, YouTube embed, analytics, real download links)
